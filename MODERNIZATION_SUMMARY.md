## 🎨 Design System Features

- **Neutrals**: Premium grays with sophisticated hierarchy

## 🔧 Technical Implementation

### **Angular Features Used**
- **Signals**: Reactive state management (`signal`, `computed`)
- **Standalone Components**: Modern Angular architecture
- **Lazy Loading**: Route-based code splitting
- **Change Detection**: OnPush strategy for performance
- **Host Bindings**: Direct host element manipulation

### **Services Created**
- `NotificationService` - Centralized alert management
- `AuthService` - Authentication and session handling
- `DashboardDataService` - Dashboard metrics aggregation
- `PaymentService` - Payment and PRN management
- `ReturnsService` - Tax returns handling
- `EtimsService` - Invoice management
- `ThemeService` - Dark/light theme switching

### **Routing**
- Protected routes with `authGuard`
- Guest-only routes with `guestGuard`
- Lazy-loaded page components
- Proper title configuration
